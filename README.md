# PHI CREATORS SUITE

PHIDM (PHI) の世界データを制作するための統合開発環境です。
サーバの world フォルダ (phi.td のある場所) を開くと、既存の世界データを
そのまま読み込んで編集を始められます。保存はサーバが読む元の形式
(CP932 / LF / `.` 終端) のままで、保存時に `.bak` が残ります。

## エディタ (全9種)

| エディタ | ファイル |
|---|---|
| 世界設定 | phi.td |
| アナウンス | phi.bb / phi.inf |
| スイッチ | phi.swt |
| エネミー | phi.ed |
| オブジェクト | phi.od |
| ゲート通過制限 | phi.ex |
| クリエイト | phi.crt |
| マスター権限 | phi.ad |
| マップ | phi.dd / phi.fd |

- 設定系は ON/OFF スイッチと数値・単語の入力欄で編集でき、各項目に
  DM のドキュメント由来の解説が付きます。
- マップはチップを描いて視覚的に編集できます (地形ペン / 塗りつぶし /
  見た目 (:T) / エリア / オブジェクトのドラッグ配置)。
- 座標が必要な項目 (エネミーの出現位置、スイッチの設置・動作位置) は
  「マップで指定」ボタンからマップをクリックして指定できます。
  マップ上には出現位置 (赤い菱形) とスイッチ位置 (水色の四角) が
  マーカー表示されます。
- マップサイズはサーバのコンパイル設定 (phi_dm.cnf の MAX_X/MAX_Y) に
  依存します。新規マップは正方形のみ、最大 1000×1000 です。

## 動作環境

Godot 4.7 製です。Releases から macOS / Windows 版を入手できます。
マップのチップ表示には Philly 等のチップフォルダ (BMP) が別途必要で、
マップエディタの「チップフォルダを選ぶ」から指定します。

## 開発

- `scripts/` — 本体 (形式パーサは未編集行のバイトを保持し、往復一致を
  テストで保証)
- `tests/` — ヘッドレステスト群 (実世界データの往復テストを含む。
  フィクスチャの世界データはリポジトリには含みません)
